Настройка Traffic Flow

На MikroTik включите экспорт потоков и укажите IP этого компьютера в сети роутера.

1

Узнайте локальный IPv4 компьютера, на котором запущен Net Control.

2

В терминале RouterOS выполните команды, заменив IP_КОМПЬЮТЕРА на этот адрес и при необходимости изменив порт:

3
Разрешите входящий UDP-порт в брандмауэре Windows и нажмите «Запустить сбор».
Для проверки API включите на RouterOS 7 службу www-ssl и выдайте пользователю необходимые права. Экспорт потоков работает независимо от проверки API.
